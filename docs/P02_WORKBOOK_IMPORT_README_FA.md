# P02 — ورود کامل اکسل، مرحلهٔ محافظت‌شده

این بسته فقط سورس را نصب می‌کند؛ نصب آن هیچ تغییری در دیتابیس، migration، بسته‌ها یا گیت نمی‌دهد.
جدول customers.0009 قبلاً با خروجی واقعی تأیید شده است؛ این مرحله migration جدید ندارد.

## دامنهٔ تأییدشده
- حفظ ۴۲۴ ردیف و تمام سلول‌های A تا M با نوع سلول و سرستون اصلی.
- ۴۲۳ دیماند قراردادی با واحد تأییدشده MW، نه خرید واقعی.
- ۳ یادداشت جدید؛ ۶۵ یادداشت قبلی و سوابق تعامل حفظ می‌شوند.
- اصلاح ۳۰ رکورد: یک حساب قبض، ۲۰ تماس، ۹ واحد صنعتی.
- انتقال حساب ۱۴۴ و تماس ۱۲۱ به پروندهٔ موجود ۷۰۱؛ پروندهٔ ۷۰۰ حذف یا ادغام نمی‌شود.
- شماره‌ها مطابق اکسل؛ صفر ابتدایی ساخته نمی‌شود. سلول خالی اطلاعات موجود را پاک نمی‌کند.
- بدون مشتری، تماس، تعامل، تغییر وضعیت، مالکیت یا تغییر شرکت دیگر.

## کنترل‌ها
- هش پیش‌نمایش واقعی تأییدشده و نسخهٔ سورس کنترل می‌شود؛ فایل داده در مخزن قرار نمی‌گیرد.
- حالت پیش‌فرض دستور فقط خواندنی است. --apply تنها پس از تأیید جداگانه و پشتیبان تازه کاربرد دارد.
- پیش از ورود، schema واقعی PostgreSQL17، identity، constraint، trigger و وابستگی‌های FK بررسی می‌شوند.
- پشتیبان قبل از ساخت جدول برای ورود داده پذیرفته نمی‌شود؛ receipt اختصاصی، هش فایل و فهرست آرشیو، مقصد و snapshot دقیق لازم‌اند.
- اعتبار پشتیبان حداکثر ۱۵ دقیقه است؛ در انقضا توقف و بررسی، نه حذف guard.
- تراکنش واحد، advisory lock و قفل کوتاه جلوگیری از نوشتن هم‌زمان روی جداول مرتبط؛ خواندن صفحات مسدود نمی‌شود. runserver متوقف بماند.
- برای ۴۲۴ ردیف، ۳ یادداشت، ۳۰ اصلاح و یک رسید کلی، مجموعاً ۴۵۸ ممیزی موفق در همان تراکنش ثبت می‌شود.
- ممیزی شامل هش تغییرات است نه متن یادداشت/اطلاعات تماس؛ عملیات به کاربر Django فرضی نسبت داده نمی‌شود.
- شکست هر نوشتن/ممیزی/اعتبارسنجی، کل دسته را rollback می‌کند. شناسه‌ها را دیتابیس تولید می‌کند؛ فاصلهٔ sequence بعد از rollback ممکن است و نشانهٔ نقص نیست.
- اجرای دوباره فقط پس از تطبیق کامل داده و ممیزی ALREADY_APPLIED و بدون نوشتن است؛ وضعیت جزئی یا متفاوت متوقف می‌شود.

## ترتیب اجرا
۱. نصب سورس؛ check؛ آزمون هدفمند.
۲. بررسی فقط‌خواندنی schema و دادهٔ تأییدشده، سپس پشتیبان تازه با ابزار جداگانه.
۳. ارسال manifest پشتیبان و تأیید قبل از دستور ورود.
۴. ورود، کنترل دوبارهٔ فقط‌خواندنی، بررسی دستی پرونده‌ها، سپس ثبت مسیرهای دقیق در گیت.

آزمون‌های محیط محلی دستیار جای آزمون واقعی PostgreSQL کاربر را نمی‌گیرند.
این سند تأیید اجرای ورود یا تکمیل نهایی P02 نیست.

## اصلاح محافظ مقایسهٔ نوع PostgreSQL
Django نوع Decimal را به‌صورت numeric(30, 6) و کاتالوگ PostgreSQL به‌صورت numeric(30,6) بازمی‌گرداند. محافظ مقایسه اکنون فقط فاصلهٔ اطراف ویرگول نوع را یکسان می‌کند. دقت ۳۰، مقیاس ۶، نوع و nullable همچنان بررسی می‌شوند؛ تغییر مدل، migration یا دیتابیس لازم نیست. تغییر دقت یا مقیاس همچنان موجب توقف است. پشتیبان‌گیری متوقف‌شدهٔ قبلی مجوز ورود نیست؛ پس از این اصلاح پشتیبان تازه ساخته می‌شود.
